# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

The Arimark team takes the security of our software and its users seriously.

If you discover a security vulnerability in Arimark, please do not report it in a public GitHub issue. Instead, please report it privately:

- Send an email to **thirumalairaj@arima.one** with details of the vulnerability.
- Include steps to reproduce, affected versions, and potential impact.

We will acknowledge receipt of your vulnerability report within 48 hours and work with you to understand and address the issue promptly.
